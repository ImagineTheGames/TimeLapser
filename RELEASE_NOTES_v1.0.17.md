# TimeLapser v1.0.17

## Region capture on multi-monitor

### Fixed

- **Region capture with multiple monitors** – Recording with a custom region could get stuck at 0 frames when using more than one display. The composite step now resizes each display’s capture to the correct dimensions so the region is extracted correctly.

### Install

Download the Windows installer from the [Releases](https://github.com/ImagineTheGames/TimeLapser/releases) page.
