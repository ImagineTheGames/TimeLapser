# TimeLapser v1.0.43 (Nightly)

**This is a nightly (experimental) build.** Use it for testing; prefer a stable release for everyday use.

## Changed

- **Start with Windows** – When Windows launches TimeLapser as a login item, the overlay stays off-screen in the system tray until you choose **Show TimeLapser** or click the tray icon. Launches from the Start menu, a shortcut, or the installer “Run when setup finishes” option still open the overlay as before.

## Install

Download the Windows installer from the [Releases](https://github.com/ImagineTheGames/TimeLapser/releases) page. This build is listed as a **Pre-release**.
