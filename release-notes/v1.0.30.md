# TimeLapser v1.0.30

## Hotfix: crop export no longer fails with "Error reinitializing filters"

### Fixed

- **Crop export crash** – Exporting with fit mode **Crop** (and optional zoom &lt; 100%) could fail with *"Error reinitializing filters! Failed to inject frame into filter network: Invalid argument"*. The filter chain now correctly handles all cases: when the scaled content is larger than the output in both dimensions we crop; when it is smaller in both we pad; when one dimension is larger and one smaller we scale to cover and crop instead of using an invalid pad. Video export also uses a concat demuxer and normalizes frame dimensions first so the filter chain never sees changing frame sizes.

Download the Windows installer from the [Releases](https://github.com/ImagineTheGames/TimeLapser/releases) page.
