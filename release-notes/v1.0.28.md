# TimeLapser v1.0.28

All changes since v1.0.24: export clarity, startup behaviour, monitor sizes, capture resolution scale, and export fit options with crop positioning.

## New

- **Capture resolution scale** – In Settings you can scale capture resolution (100%, 75%, 50%, 25%) to reduce disk usage. Default is 50%. Applies to all capture sources.
- **Export fit mode** – Export dialog now offers **Letterbox**, **Crop**, or **Stretch** (replacing the single “Crop to fit” checkbox). Stretch is the default.
- **Crop position** – When fit mode is Crop, you can drag a frame on the first-frame preview to choose which part of the recording is exported (e.g. center, top, corner).
- **Custom preset: match recording size** – Custom export preset can use “Match recording size” so output dimensions match the recording with no aspect change.

## Changed

- **Export: target video length** – The “Target video length (s)” option now includes the line “How long your timelapse will be.” so it’s clear what this setting does.
- **Startup: always show window** – When you launch the app (e.g. from the installer “Run” or the Start menu), the overlay window is always shown. “Start with Windows” only controls whether the app runs at login; it no longer starts minimized to the tray.
- **Export: last fit mode saved** – Your last chosen fit mode (letterbox/crop/stretch) is saved and restored the next time you open the export dialog.

## Fixed

- **Monitor sizes in packaged app** – In the packaged build, the monitor list now uses Electron only so each display’s name and size stay in sync. Physical resolution uses the primary display’s scale factor when needed so sizes are correct on Windows.
- **Off-by-one resolution** – Display resolutions are snapped to common values (e.g. 3440×1440) when within 1 pixel so ultrawide and other standard sizes show correctly (e.g. 3441 → 3440).
