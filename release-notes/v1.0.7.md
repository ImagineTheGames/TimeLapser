# TimeLapser v1.0.7

## GIF export: simple sliders and fine resolution

This release improves GIF and LinkedIn GIF export so you can tune output size and quality more precisely.

### New and improved

- **Simple sliders (easy mode)** for GIF and LinkedIn GIF:
  - **Number of frames** – Set the exact target frame count (or "No limit" for plain GIF). The encoder keeps your frame count and scales resolution to fit the file size limit.
  - **Resolution (min. long side)** – Slider from **240 px to 1080 px** in 30 px steps so you can find the sweet spot for file size (e.g. stay under 5 MB for LinkedIn). Option **Full resolution (no cap)** for uncapped size.
  - **Target file size** – Slider for max file size (0.5–5 MB for LinkedIn, 0.5–25 MB for plain GIF, or No limit).
  - **FPS** – Slider 5–15 for output frame rate.

- **Result preview** – When exporting to GIF or LinkedIn GIF, the dialog shows a live **Result preview**: output frames, output FPS, resolution (W×H), duration, and estimated file size. For LinkedIn, a note appears if the estimate is over 5 MB.

- **Resolution floor** – Your chosen resolution is respected as a minimum; the app scales down only when needed to meet the file size limit, so the resolution slider always has an effect.

- **Trade-off hint** – Short copy explains how lower resolution, fewer frames, or higher FPS affect file size and duration.

### Other

- Per-target **video format** (MP4 / WebM / MOV) and **GIF** as a preset in the "Export to" dropdown; path and options stay consistent per target (e.g. `.gif` for GIF).
- LinkedIn GIF preset: 5 MB, 500 frames; prioritizes your chosen frame count and scales resolution to fit.
