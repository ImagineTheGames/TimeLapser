# TimeLapser v1.0.42

## New

- **Export: maximize duration under size limit** – When a max file size is set, you can enable "maximize duration under limit" so the exporter keeps all frames and picks FPS to get the longest video under the cap (trial exports until ~0.1 MB under).
- **Faster capture interval** – Minimum capture interval is now 0.01 s (was 0.1 s) for higher frame-rate timelapses.

## Changed

- **Export dialog** – "FPS" labels are now "Playback FPS" for clarity in the export UI.

## Install

Download the Windows installer from the [Releases](https://github.com/ImagineTheGames/TimeLapser/releases) page.
