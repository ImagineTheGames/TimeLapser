# TimeLapser v1.0.29

## Crop zoom and export/test improvements

### New

- **Crop zoom** – When export fit mode is **Crop**, a **Zoom** slider (50%–100%) lets you show more of the recording in the frame. At 100% the frame is filled (crop overflow); at lower values the image is scaled down so more content is visible (letterbox-style). The crop position preview and export preview both reflect the zoom. Your last crop zoom is saved when fit mode is crop.
- **Test UI flag** – The "Automated recording test" section in Settings is shown only when the app is started with `--test` or `-test`, keeping the normal UI cleaner. Export zoom can be tested via `--test-export-zoom`.

### Changed

- **Export dialog** – "Target video length (s)" label is now "Timelapse length (s)" with a tighter layout. "Add another format…" is now "Add another export…". Fit-mode hint styling and labels adjusted. Crop position preview supports zoomed-out (zoom &lt; 100%) view.
- **Settings panel** – Recording test block is conditional on the test flag; main process exposes `showTestUI` via startup flags.
- **Overlay panel** – When the settings panel is expanded, the overlay always grows to the right (panel to the right of the bar); simplified positioning logic.

### Fixed

- **Export with crop zoom** – Video and GIF export now apply the crop zoom (0.5–1) correctly: scale between contain and cover, then crop or pad so output dimensions are exact. Previews in the export dialog match the exported result.
- **Export targets during export** – Export uses a ref to the current targets list so rapid UI updates during export don’t change which targets are exported.
