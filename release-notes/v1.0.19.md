# TimeLapser v1.0.19

## Region across multiple monitors

### Fixed

- **Region capture spanning multiple monitors** – Recording a region that crosses two or more displays could stay at 0 frames. The multi-monitor composite now clamps sizes and positions and uses a consistent RGBA format so the composite step succeeds. If it still fails (e.g. display order mismatch), the app falls back to capturing the first intersecting display so you get frames instead of none.
